Excelerator Password Support

Support for locking, unlocking, and modernizing supported Microsoft Excel workbook files on macOS.

Email Support Privacy Policy

Contact

For support, contact jmsdesignnyc@gmail.com.

Do not include workbook passwords in support requests.

Supported Formats

  • .xlsx
  • .xlsm
  • .xls

Lock

Use Lock to apply a file-open password to supported workbooks. The processed workbook remains at the expected output location after successful processing.

Unlock

Use Unlock to remove a known file-open password from supported workbooks. Incorrect passwords fail closed and do not replace the original file.

Dock Drop

Supported workbooks can be dropped on the Dock icon for quick processing. Dock Drop uses the app's current saved settings and selected client context.

Legacy .xls Modernization

The original .xls file is preserved and Excelerator Password creates a modernized .xlsx copy for processing.

If macOS requires authorization for the new .xlsx, a normal Save dialog may appear.

Passwords and Keychain

Client profiles can store saved workbook passwords. Saved passwords use macOS Keychain.

Clear All App Data

Settings includes Clear All App Data for removing Excelerator Password-owned local data. It removes client profiles, associated saved Keychain passwords, settings, app-owned activity state, and app-owned temporary data after confirmation.

Clear All App Data does not delete Excel workbook files, processed workbooks, converted .xlsx files, or unrelated Keychain items.

Wrong Password Behavior

If a password is rejected, verify the selected client profile and workbook password. The app should not replace the original workbook after an incorrect password.

Malformed or Unsupported Workbooks

If a workbook is malformed, damaged, or not a supported Excel workbook type, processing fails and the original file should remain unchanged.

Basic Troubleshooting

  • Confirm the workbook extension is .xlsx, .xlsm, or .xls.
  • Confirm the selected client profile uses the correct password.
  • Confirm macOS allows access to the selected file location.
  • If a Save dialog appears during legacy .xls modernization, choose the intended location for the new .xlsx copy.
  • Check the bundled User Guide and Quick Start from the app's Help menu.

User Guide and Quick Start

Version 1.3.0 includes bundled User Guide and Quick Start documentation in the app bundle. Open them from the Help menu inside Excelerator Password.

Privacy
